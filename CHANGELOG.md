# Changelog

All notable changes to RentFlow are recorded here.

## Unreleased

### Changed

- Repositioned RentFlow as a 2027 Final Year Project and market-oriented rental operations platform.
- Changed the canonical implementation stack from Next.js/Supabase to a Laravel monolith.
- Selected Laravel + PHP + Blade + Livewire + Tailwind CSS + MySQL 8+ as the implementation direction.
- Updated architecture, database, integration, security, testing, deployment, research and roadmap documentation for Laravel.

### Removed

- Previous Next.js/TypeScript application implementation from `masterchanges`.
- Next.js, TypeScript and ESLint configuration from the active implementation branch.
- npm application package manifests/lockfile from the active implementation branch.
- Supabase scaffolding and the previous application environment template.

### Added

- Final Year Project proposal baseline.
- Software Requirements Specification (SRS).
- Research and evaluation plan.
- Laravel-focused testing strategy.
- Laravel deployment/environment strategy.
- MySQL/Eloquent schema blueprint.
- Architecture decision records documenting the switch to Laravel/MySQL.

## Historical Prototype — 9 September 2026

The original Next.js prototype/bootstrap was merged into `main` through PR #1. It remains available through Git history but is no longer the canonical 2027 FYP implementation direction.
